# Contributing to Open Energy Collective

Thanks for helping. This file applies to every repo in the organisation that has no CONTRIBUTING.md of its own.

## Where to ask

Ask questions and request access in the organisation's [Discussions](https://github.com/Open-Energy-Collective/.github/discussions). Use an issue in the repo concerned only for something that is wrong or missing.

## Report a tariff error

Open an issue in tariff-service with:

- the DNSP
- the tariff code
- the page of the DNSP's approved price list that shows the rate
- the value you expected
- the value the API returns

## Propose a change

1. Open an issue that says what you want to change and why. Wait for the maintainer to agree before you write code.
2. Fork the repo and make the change.
3. Open a pull request against the open release branch (named `feat/X.Y.Z`). The issue tells you which one is open. Do not target `main`.

## Run the tests

Each repo's README says how to install its dependencies and run its tests. Run them before you open a pull request, and say in the pull request what you ran.

## Licence of contributions

A contribution is licensed under the licence of the repo it goes into. The repo's LICENSE file names it. By opening a pull request you agree to that.
